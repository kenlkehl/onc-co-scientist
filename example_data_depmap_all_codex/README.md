# Historical benchmark artifact

This directory preserves the original 50,000-row single-CRC demonstration,
including its saved harness transcripts and scores. It is not generated by,
or referenced from, the active example configuration. Current generation uses
five 2,000-model DepMap tasks (10,000 model records total) through
`configs/synthetic.example.yaml`; `configs/co_scientist.example.yaml` points
to those current outputs under `data/ds001/tasks/`.
