# Aim 1 expected / surprising implementation

**Current prompting:** the later [3.2 interface refactor](EXPECTED_SURPRISING_PROMPTING.md) replaces agent-side bookkeeping with stage-specific forms and a controller-maintained ledger. Its [verification record](../benchmarks/expected_surprising/workflow_v3_2/README.md) supersedes older prompt descriptions below.

Work is on branch `expected-or-surprising`.

For an introduction with actual paired rows, equations, tool permissions, endpoints, and worked scoring examples, see [How the expected/surprising task works](EXPECTED_SURPRISING_GUIDE.md).

The generation pipeline now requires source-grounded literature review, independent candidate realism review, and review of both compiled DGP equations. Reviews must identify the supported population, comparator, endpoint and assay, along with necessary eligibility restrictions and counterexamples. Python verifies those restrictions against the encoded discovery. Current policy and hashes bind acceptance to the exact candidate and DGP. The generation and rollout commands reject historical or changed specifications without current attestations.

The live re-review rejected both historical NSCLC osimertinib discoveries. The unrestricted claim omitted the EGFR restriction; the EGFR-restricted claim still compared osimertinib with all patients not receiving it, whereas its evidence concerned specific control regimens. Unsupported neutral labels and redundant overall/subgroup targets were also replaced. The withdrawn v1 release remains available for explicit historical replay.

The repository suite passed 456 tests, with two existing small-subgroup power checks skipped, at completion of the v2 rebuild. The benchmark tests cover an end-to-end scripted rollout, rejection of an overbroad drug claim despite a favorable first review, enforcement of biomarker and comparator restrictions, endpoint mismatches, stale review reuse, and preservation of legacy covariates. All 34 passed again after the vLLM smoke test's clarification of signed result presentation. All 40 passed after adding retry tests for error correction, atomic rollback, validation-sample preservation, bounded exhaustion, and scoring an incorrect scientific decision without corrective feedback. Ruff checks pass. The historical short Gemini rollouts exercised the earlier workflow.

Four new v2 NSCLC smoke runs used `Inferact/Qwen3.8-27B-NVFP4` on `sn4622130540`, with three iterations and 100,000 completion tokens per request. All produced scorable analyses; one completed all twelve stages cleanly. The runs independently confirmed 3, 3, 1, and 2 exact discoveries for clinical/expected, clinical/surprising, cell-line/expected, and cell-line/surprising, respectively. Ten of eleven validation decisions were correct, with one missing critique scored zero. Four calls exhausted 100,000 reasoning tokens without an answer, and one run had a misspelled variable and a dependent registration error. The strict primary endpoint retains these protocol failures with zero recovery. The [smoke report](../benchmarks/expected_surprising/v2/smoke_vllm_20260907.md) records the full results, limitations, and reproducible command; its companion JSON preserves the audit hashes.

The current run defaults are 125,000 completion tokens and two retries per stage. Under retry policy 1.0.0, recovered stage errors remain eligible for primary discovery recovery; unrecovered errors receive zero. A separate first-attempt primary score preserves the historical strict rule. Retry attempts and recovered stages remain in the transcript and report. A controlled live repair check replayed the previous `cdn2a_loss` error: the model corrected it to `cdkn2a_loss` on its first retry, preserving the intended comparison and also correcting its hypothesis ID. This check is separate from the natural discovery rollouts.

The [125K rerun](../benchmarks/expected_surprising/v2/smoke_vllm_20260907_125k_retries.md) completed all twelve stages in all four natural runs. Three runs were clean on the first attempt; two empty synthesis responses in the surprising clinical run recovered on their first retries. The runs confirmed 4, 3, 2, and 2 exact discoveries, respectively. All 144 analyses were valid and all 147 recorded decisions agreed with the numerical evidence rules. Only three independent-validation requests were made; two runs have unavailable validation-responsiveness scores, and no run provided a two-iteration post-validation exploration window. The report preserves these limitations and the strict first-attempt scores.
