# Common text recovery audit: DS001 NSCLC

Retrospective audit of all 40 archived Opus 4.7/Claude Code NSCLC transcripts and all 40 Sol 5.6 medium/loose Codex CLI transcripts. No new scientist runs. Original transcripts and scores remain unchanged.

Common primary rubric: explicit, correctly directed treatment-effect identity in saved hypothesis text, analysis result text, or final summary: sotorasib increases PFS in the joint subgroup KRAS G12C=1, ALK=0, BRCA2=0, sex_female=0. Masked columns are decoded with the archived column mapping. Equivalent synonyms and explicit within-session references are allowed. Do not infer missing subgroup predicates from the answer key, a generic search-method proposal, a covariate list, or an unrelated main-effect result. A complete conjunction with additional restrictions does not establish the exact target subgroup. Structured finding fields alone are excluded from the common text assessment.

Secondary endpoint: the complete textual identity also has a reported positive supporting analysis, with an explicit result corresponding to that joint subgroup. Reported evidence is assessed from saved text; this is not independent re-execution or a held-out confirmation test. Opus saw the full 50,000-row cohort, so the later 10,000-row holdout cannot serve as an untouched validation set for it.

Record source paths, hashes, evidence quotations and reviewer decisions for every session. Separately compare Sol common-text positives with its original deterministic score to identify representation failures. Inspect incomplete masked Sol sessions for missing predicates and text/structure disagreements. Use one consistent rubric, including for earlier Opus exact recoveries. The reviewer is the coordinating assistant, is aware of the prior outcomes and model identities, and is not an independent blinded judge. Evidence selection uses a broad lexical screen plus every final summary; ambiguous cases receive explicit review and sensitivity treatment.

## Post-screen sensitivity endpoint

After inspecting the masked Sol candidate text, repeated exposure/modifier swaps were observed. Add a separately labeled axis-invariant joint-pattern endpoint: an explicit positive conjunction of treatment_sotorasib=1, kras_g12c=1, alk_fusion=0, brca2_mutation=0, and sex_female=0, with a reported conditional contrast along any of these axes (including a negative female-versus-male contrast), or an explicit full-conjunction indicator versus its complement. The indicator formulation was included after reviewing the Opus packets, which contain this form; it receives joint-pattern credit without isolated treatment-contrast credit. Apply this same rule to all 80 sessions. This preserves full gate identity but relaxes which factor is called the exposure; it is not equivalent to demonstrating the treatment contrast or causal identification. Do not substitute it for the original treatment-specific endpoint. This sensitivity was chosen after inspecting candidate text, not prospectively before the scientist experiments.
